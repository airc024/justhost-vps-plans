## “不限流量”到底是什么意思

JustHost 每个套餐写的都是“不限流量端口”，后面跟一个括号：公平共享（fair-share）。这句话值得拆开看。

不限制每月跑多少 GB，限制的是端口速率。10Mbps 端口满速下载大约 1.25MB/s，一个月不停跑理论上限在 4TB 左右，官网标注的“4+ TB/月”就是这么折算出来的。300Mbps 对应 93+ TB，750Mbps 对应 232+ TB。这些数字是数学上限，不是你能稳定拿到的量。

真实情况是同一台母机上的用户共享这条端口，高峰期大家抢带宽。官网对此的表述很直接：不限流量端口采用公平共享机制，不是独享带宽，也不保证持续满速。

对用途的影响很具体：

- 跑 API 请求、定时任务、爬虫、监控，10Mbps 完全够，瓶颈在对方服务器不在你的端口
- 小博客、文字站，10Mbps 也能撑，一天几百个访问量看不出差别
- 图片多的站、有下载的站，10Mbps 会明显慢，一个页面 1MB，同时来十个人就开始排队
- 想做视频、CDN、大文件分发，这个价位段不适合，共享端口扛不住持续满载

## 机房和线路：为什么同一个套餐价格不一样

低价 VPS 的价格差异，基本由这几项决定：

- **线路等级**：普通国际线路直连最便宜；AS4837、AS9929、CMI 这类优化线路贵一档；三网回程 CN2 GIA 再贵一档
- **IP 属性**：广播 IP 便宜，原生 IP 贵。要过平台风控、要解锁流媒体，IP 纯净度比配置更关键
- **端口速率与流量**：10Mbps 和 750Mbps 不是一个成本
- **硬盘类型**：表三已经算过，HDD 到 NVMe 每月差一到三美元

对应的决策线也很清楚：只需要一个海外 IP 把东西跑起来，买最便宜的国际线路档；要国内访问稳定，为优化线路付溢价；要过风控或解锁，先确认 IP 属性，光看线路不够。

JustHost 抓到的套餐页把价格差异体现在机房、端口速率和硬盘类型上，没有在每个套餐旁标注回程线路等级。如果你买它是为了国内访问，选机房这一步比选配置更重要，先用 looking-glass 看回程，再决定要不要为某个机房多付钱。

## 常见问题

**低价 VPS 能建站吗？**
能，但要 20GB 硬盘加 1GB 内存起步。5GB 那档装完系统就剩一半空间，跑不动数据库。

**为什么高峰期会变慢？**
端口是公平共享，同机用户一起抢带宽。10Mbps 端口本来就只有 1.25MB/s，高峰期分到的更少。

**年付还是月付？**
看使用时长。用不到半年就月付或首期 5 折；打算长期用，11VPS40 的 6 折且续费同折，比年付 8 折便宜，第二年也不涨。

**10Mbps 端口够用吗？**
跑脚本、调 API、文字站够用。有图片、有下载、有并发就不够，至少上 100Mbps 那档。

**优惠码在哪填？**
结账页有优惠码输入框。一笔订单只能用一个码，不能和年付折扣叠加，填之前先算一遍哪个更省。

**能退款吗？**
